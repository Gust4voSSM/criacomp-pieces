# Close-ups das mãos no Qwen

Recortes das imagens originais, sem retoque. O alpha original foi composto sobre branco; ampliações usam nearest-neighbor.

- maos-pose-perna-levantada-closeup.png: duas mãos da pose falando anterior à simplificação; ampliação 3×.
- mao-quadril-closeup.png: mão junto ao quadril na pose simplificada com CFG 1; ampliação 4×.
- cfg2-control-closeup.png e cfg2-negative-closeup.png: mão na cintura com CFG 2, sem e com negativos; ampliação 4×.
- comparacao-mao-cintura-cfg.png: CFG 1, CFG 2 controle e CFG 2 com negativos, na mesma escala 4×.

Os arquivos *-original.png preservam os recortes RGBA em resolução nativa. Proveniência, coordenadas dos recortes e SHA-256 das fontes estão nos três arquivos provenance*.json.
